# CS30 Major Project Reflection - Graham Lindsay

## What advice would you give to yourself if you were to start a project like this again?
 - Focus more on the main function of the project in the beginning, and don't put off solving issues with the code. It was more complicated than I thought it was going to be, so I underestimated how much time it would take to implement certain features.
## Did you complete everything in your "needs to have" list?
 - I did, the only thing was that I ended up choosing not to add music because it didn't seem to fit the project. I did add sound effects and i was able to add everything that was on my "needs to have list". I was also able to add compatibility for 2x2 cubes (technically any size, but for larger cubes, you cant turn the middle rows) for my "want to have list", but I ran out of time to add a way to change the size from the running project, right now you can only change it in the code.

## What was the hardest part of the project?
 - The hardest part was dealing with the rotation logic for the cube. I spent the most time by far on getting it working and I had lots of frustrating moments when trying to solve those problems. Working in 3D with p5js was also fairly difficult. Some of the ways p5js handles positioning and movement in 3D space are not intuitive. 

## Were there any problems you could not solve?
 - There was only one thing I wasn't able to solve, which was getting the timer not to count up when you when you are holding it on green. Its not too big of an issue and it should be easy to solve, but I found it yesterday, so I didn't have time to fully fix it.
